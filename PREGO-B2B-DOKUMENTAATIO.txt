6. TIETOKANTA (Neon)
--------------------
Migraatiot: migrations/*.sql  (ajetaan npm run build / db:migrate)
  0001_auth.sql             Better Auth -taulut (user, session, account, verification)
  0002_schema.sql           profiles, products, orders, order_items, settings, email_log, import_log
  0003_product_details.sql  image_url, datasheet_url, features_*

Tärkeät taulut:
  profiles      user_id, email, company_name, vat_number, role, approved_at
                role: pending | customer | admin
  products      sku (PK), ean, name_fi/en/sv/no/et, category_*, product_group,
                net_price, carton_qty, stock, incoming, reserved, backorder, eta, active,
                image_url, datasheet_url, features_fi/en/sv/no/et
  orders        order_no, status, osoitteet, net/vat/grand
                status: submitted | confirmed | processing | shipped | cancelled
  order_items   sku, qty, unit_price, line_total
  settings      order_email, company_name, vat_rate, brand_name
  email_log     lähetetyt tilausviestit (vaikka Resend epäonnistuisi, rivi jää)

Ensimmäinen rekisteröitynyt käyttäjä saa roolin admin.
Seuraavat saavat pending. Admin hyväksyy: Ylläpito → Asiakkaat → Hyväksy.

Tuotekanta seedataan tyhjään kantaan tiedostosta src/data/products.json
(seedIfEmpty). Tuotannossa Neon on jo seedattu; älä tyhjennä kantaa kevyin perustein.

Palautus: Neon-konsoli → Restore / Time Travel.
  Ilmainen tili: n. 6 tuntia historiaa — B2B:lle liian lyhyt.
  Launch-paketti: pidempi ikkuna.
  Admin-paneelista voi ladata CSV-varmuuskopiot (tuotteet, asiakkaat, tilaukset).

9. LIIKESÄÄNNÖT
---------------
Hinnat ja myyntierä: vain kirjautunut JA hyväksytty (customer|admin).
Vieras ja pending näkevät valikoiman ilman hintoja.

Asiakasnäkymä piilottaa tuotteen jos:
  - active = false TAI
  - stock = 0 JA eta ei sisällä vuotta (pelkkä "30.9" ei riitä; "30.9.2026" riittää)

Varasto väreinä, ei lukuina:
  vihreä  stock > 10
  keltainen  1–10
  punainen  0 (näkyy vain jos on kelvollinen ETA)

Tilausmäärä pyöristetään myyntierään (carton_qty) ylöspäin.
Minimitilaus 300 € veroton (alv 0). Estetään korissa, kassalla ja palvelimella.

Uusi yritys: register → role pending → admin Hyväksy → customer.
Pending ei pääse koriin, kassalle eikä tilaushistoriaan.

Tilaus → tallennetaan Neon → sähköposti settings.order_email -osoitteisiin
(pilkulla useampi) + kopio tilaajalle. PDF ladattavissa tilaussivulta.

ALV 25,5 % oletus; käännetty verovelvollisuus = 0 %.

16. TUNNETUT KUOPAT
-------------------
- Zip GitHubiin = Vercel ei käytä koodia. Git tarvitsee kansiot, ei .zip-tiedostoa.
- .vercel-kansion commit = vanha sivusto jää voimaan.
- Env-muuttuja ei vaikuta ennen Redeploytä.
- BETTER_AUTH_URL väärin → kirjautuminen hajoaa (eväste / callback).
- Excel ETA ilman vuotta (30.9) ei tuo tuotetta valikoimaan.
- PGLite devissä ≠ Neon tuotanto. Admin-Excel päivittää sen kannan jossa
  DATABASE_URL osoittaa.
